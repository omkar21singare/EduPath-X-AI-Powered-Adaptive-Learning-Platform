# EduPath-X — Content Source Registry & Data Integrity Policy

## Absolute Data Integrity Rule

EduPath-X strictly adheres to scientific educational transparency:
- **No Fabricated Facts**: Educational materials and question explanations are verified against computer science standards.
- **No Scraping Copyrighted Textbooks**: Original concise explanations and original problem sets were written for EduPath-X based on accredited open educational resources.
- **Explicit Source Registry**: Every material and question references its underlying source via the `content_sources` table.

## Content Distinction Categories

1. **SOURCE CONTENT**: Verified canonical algorithms, asymptotic complexity definitions, and data structure invariants.
2. **EDUPATH-X ORIGINAL CONTENT**: Concise explanations, original code examples, and practice question items written specifically for the platform.
3. **LEARNER-GENERATED DATA**: Real question attempts, response times, BKT prior/posterior records, and session logs.
